# Frontend Engineering Portfolio

This repository contains a collection of three frontend development projects completed as part of team-based software projects.

Each project demonstrates experience in building modern web interfaces, working with APIs, developing dashboards, and implementing frontend features for real-world applications.

The source code and related information for each project can be found in the following sections.

---

## Projects

### 1. Hospital Management System

A web-based healthcare management platform developed to support hospital operations and administrative workflows.

As a frontend developer, I contributed to implementing user interfaces, management dashboards, and frontend features required for different system modules.

Repository:
[[Project Link](https://github.com/Hospital-Managment)]


---

### 2. Game Analytics Dashboard

A data-driven dashboard platform designed for game developers to monitor and analyze their applications.

The system allows users to view information such as sales performance, player activity, game progress, user levels, and other application metrics through API-based data visualization.

As a frontend developer, I worked on implementing dashboard interfaces and integrating frontend components with backend APIs.

Repository:
[[Project Link](https://github.com/Odyssey-analytic)]


---

### 3. Mobile Signal Analysis Platform

A web platform developed for analyzing mobile signal data collected from user devices.

The system processes signal information to help companies evaluate network performance, identify weak coverage areas, and make decisions regarding infrastructure improvements.

I contributed to frontend development, including interface implementation and visualization of analysis results.

Repository:
[[Project Link](https://github.com/Polaris-IUST)]
