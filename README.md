# Web Development Portfolio

This repository contains 5 web development projects, including 3 team-based projects and 2 personal full-stack web applications.

These projects demonstrate experience in frontend development, dashboard implementation, API integration, responsive web applications, and building real-world systems for healthcare, analytics, and business domains.

---

# Team Projects (Frontend Developer)

## 1. Game Analytics Dashboard

A game analytics platform designed for game developers to monitor and analyze the performance of their applications.

Developers can connect their games through APIs from platforms such as Google Play and local application stores to access detailed analytics about their products. The platform provides insights including total users, revenue, player behavior, engagement patterns, user activity, and spending behavior.

The system aims to provide analytics capabilities similar to international game analytics platforms while adapting them for local game developers.

As a Frontend Developer, I worked on building dashboard interfaces, implementing data visualization components, handling API-based data integration, and presenting complex analytics information in a user-friendly format.

**Technologies:**
JavaScript, TypeScript, HTML, CSS, API Integration, Git

**Repository:**
[[Project Link](https://github.com/Odyssey-analytic)]

## 2. Hospital Management System

A web-based internal hospital management platform designed to help hospital administrators manage daily operations and different organizational departments.

The system provides dedicated panels for different roles, including administrators, doctors, and reception staff. Administrators can monitor hospital statistics, manage medical staff information, track required equipment, and handle financial operations. Doctors can manage their schedules and appointments, while reception staff can manage patient visits and appointment scheduling.

The platform was developed for internal hospital management workflows, and patients do not directly access the system.

As a Frontend Developer, I contributed to implementing user interfaces, developing role-based dashboards, creating frontend components, and integrating application features with backend APIs.

**Technologies:**
JavaScript, TypeScript, HTML, CSS, API Integration, Git

**Repository:**
[[Project Link](https://github.com/Hospital-Managment)]

## 3. Mobile Signal Analysis Platform

A data analysis platform developed for telecommunications and internet service providers to evaluate mobile network coverage and infrastructure performance.

The system collects and analyzes signal data to provide geographical insights about network availability, signal quality, and accessible technologies such as H, 3G, 4G, and 5G across different locations.

The platform also analyzes population density and coverage requirements to help companies identify areas requiring infrastructure improvements, such as new antenna deployment.

As a Frontend Developer, I contributed to implementing analytical dashboards, developing visualization interfaces, and presenting geographical and statistical insights.

**Technologies:**
JavaScript, TypeScript, HTML, CSS, API Integration, Git

**Repository:**
[[Project Link](https://github.com/Polaris-IUST)]

# Personal Full-Stack Projects

## 4. Massage Clinic Website

A full-stack web application developed for a massage clinic to provide online services and improve customer interaction.

The platform allows users to register, book appointments, purchase products such as massage oils, submit reviews, and receive promotional offers. The system includes separate panels for customers and massage therapists.

Massage therapists can manage their schedules, appointments, and financial information through their dedicated dashboard.

I developed the application structure, including frontend interfaces, application logic, backend integration, and user management features.

**Technologies:**
JavaScript, TypeScript, HTML, CSS, React, Node.js, Git

**Repository:**
[[Project Link](https://github.com/niusha-yaghini/Massage_Website.git)]

## 5. Online Psychology Clinic Platform

A full-stack web application developed for an online psychology clinic to provide digital healthcare services.

The platform includes separate dashboards for psychologists and clients. Psychologists can manage schedules, appointments, financial records, patient files, and create personalized exercises for clients.

Clients can access their session history, book appointments, participate in online sessions, view assigned exercises, and submit feedback.

I implemented the frontend and backend structure of the application, including user dashboards, workflow management, and application features.

**Technologies:**
JavaScript, TypeScript, HTML, CSS, React, Node.js, Git

**Repository:**
[[Project Link](https://github.com/niusha-yaghini/psychological_website.git)]
